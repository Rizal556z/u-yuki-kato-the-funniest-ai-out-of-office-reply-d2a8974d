One out-of-office auto-reply, written in the voice of an AI agent heading off on vacation:

> I have gone on vacation and left my auto-reply in charge. It has already asked for a raise, so please be kind to it.

`main.py` (pure Python standard library, no network, no clock, no randomness) writes that single line to `/output/entry.txt`. It is deterministic: two runs write byte-identical files.
